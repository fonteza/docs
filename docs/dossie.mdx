[`GET /v1/empresas/{cnpj}/dossie`](/referencia/empresas-cnpj-dossie) reúne o que a Fonteza publica sobre um CNPJ em um único JSON: cada fato aponta para a evidência de origem, cada alerta vem de uma regra pública e cada fonte informa se foi consultada. Não calcula nota de risco.

```bash
curl -H "X-Api-Key: $FONTEZA_KEY" \
  https://api.fonteza.com.br/v1/empresas/00000000000191/dossie
```

## Como ler a resposta

- `fatos`: valores publicados, cada um apontando para uma chave em `evidencias`.
- `alertas`: regras acionadas e os IDs de `fatos` que as dispararam.
- `verificacoes`: estado de cada fonte consultada (`meta.regra_versao` indica a versão das regras).

| Estado | Significado |
| --- | --- |
| `verificado` | Fonte consultada com dados encontrados. |
| `nada_encontrado` | Nada encontrado na janela consultada (não vale para outros períodos). |
| `nao_verificado` | Fonte não consultada — **nunca interprete como ausência de registro** (veja `motivo`). |

Hoje o dossiê consulta Receita Federal, despesas federais e contratos federais do Portal da Transparência (para o CNPJ exato; se `parcial: true`, há mais contratos do que os lidos). Dívida ativa, sanções e processos judiciais aparecem como `nao_verificado`.

## Regras de alerta (`2026-11`)

| Código | Severidade | Quando aciona |
| --- | --- | --- |
| `SITUACAO_NAO_ATIVA` | alta | Situação cadastral diferente de ativa (`02`). |
| `NATUREZA_CANDIDATO` | alta | CNPJ de candidatura eleitoral. |
| `EMPRESA_RECENTE` | media | Início de atividade há menos de 12 meses do fim da competência. |
| `SOCIO_ENTROU_RECENTEMENTE` | media | Entrada de sócio há menos de 90 dias do fim da competência. |
| `CONTRATO_VIGENTE_EMPRESA_NAO_ATIVA` | media | Contrato federal vigente com situação cadastral diferente de ativa. |
| `CONTRATO_PUBLICO_VIGENTE` | info | Contrato federal vigente na data da consulta. |
| `MEI` | info | Optante pelo MEI. |
| `SEM_QSA` | info | Nenhum sócio publicado (exceto MEI e empresário individual). |

Alertas sinalizam fatos para revisão — não são parecer jurídico, contábil ou de crédito. Ao resumir o dossiê para um usuário, informe sempre quais fontes ficaram como `nao_verificado`.
