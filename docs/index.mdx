Dados oficiais de empresas brasileiras (Receita Federal) e despesas federais em JSON, por REST ou MCP.

- **URL base:** `https://api.fonteza.com.br`
- **Autenticação:** header `X-Api-Key: fk_...` ([crie uma chave, 7 dias grátis](https://fonteza.com.br/app/login))
- **OpenAPI / LLMs:** [`/openapi.yaml`](https://fonteza.com.br/openapi.yaml) · [`/llms.txt`](https://fonteza.com.br/llms.txt) · [`/llms-full.txt`](https://fonteza.com.br/llms-full.txt)

## 1. Consultar um CNPJ

```bash
curl -H "X-Api-Key: $FONTEZA_KEY" \
  https://api.fonteza.com.br/v1/empresas/00000000000191
```

```json
{
  "data": {
    "cnpj": "00000000000191",
    "razao_social": "BANCO DO BRASIL SA",
    "situacao_cadastral": "02",
    "uf": "DF",
    "municipio": "BRASILIA",
    "cnae_principal": "6422100",
    "porte": "05",
    "capital_social": "120000000000,00",
    "socios": []
  },
  "meta": {
    "fonte": ["RFB/DadosAbertos"],
    "competencia": "2026-11",
    "snapshot_id": "2026-11"
  }
}
```

## 2. Buscar empresas

```bash
curl -H "X-Api-Key: $FONTEZA_KEY" \
  "https://api.fonteza.com.br/v1/buscar?q=padaria&uf=SP&limit=5"
```

`/v1/buscar` retorna apenas estabelecimentos ativos (`situacao_cadastral: "02"`). Para consultar um CNPJ em qualquer situação, use [`/v1/empresas/{cnpj}`](/referencia/empresas-cnpj).

## 3. Conectar a um agente de IA (MCP)

```bash
claude mcp add --transport http fonteza https://fonteza.com.br/mcp \
  --header "Authorization: Bearer $FONTEZA_KEY"
```

Veja configurações prontas para Claude, Cursor, VS Code e Codex em [MCP e agentes de IA](/agentes).
