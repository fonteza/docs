Cadastro oficial de empresas brasileiras e números de mercado — **prontos para agentes de IA via MCP** e disponíveis em REST/JSON.

- **MCP remoto:** `https://fonteza.com.br/mcp` (OAuth 2.1 ou `Authorization: Bearer fk_...`)
- **API REST:** `https://api.fonteza.com.br` (`X-Api-Key: fk_...`)
- **Chave de API:** [crie no painel (7 dias grátis)](https://fonteza.com.br/app/login)
- **Para agentes:** [`/llms.txt`](https://fonteza.com.br/llms.txt) · [`/llms-full.txt`](https://fonteza.com.br/llms-full.txt) · [`/openapi.yaml`](https://fonteza.com.br/openapi.yaml)

## 1. Conectar via MCP (recomendado)

```bash
claude mcp add --transport http fonteza https://fonteza.com.br/mcp \
  --header "Authorization: Bearer $FONTEZA_KEY"
```

Configurações prontas para **claude.ai**, **Claude Desktop**, **Cursor**, **VS Code** e **Codex** em [MCP](/agentes).

## 2. Ou chamar a API REST

```bash
curl -H "X-Api-Key: $FONTEZA_KEY" \
  https://api.fonteza.com.br/v1/empresas/12345678000190
```
