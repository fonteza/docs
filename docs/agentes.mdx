Conecte agentes à Fonteza via MCP remoto, ou entregue a documentação em Markdown diretamente ao modelo.

## MCP remoto

- **Endpoint:** `https://fonteza.com.br/mcp` (Streamable HTTP)
- **Autenticação:** OAuth 2.1 (conectores do Claude) ou `Authorization: Bearer fk_...`

### Claude (OAuth)

- **Claude Code (plugin):** rode `/plugin marketplace add fonteza/claude-plugins`, depois `/plugin install fonteza@fonteza`, e autentique com `/mcp`.
- **claude.ai e Claude Desktop:** vá em **Configurações → Conectores → Adicionar conector personalizado**, informe `https://fonteza.com.br/mcp` e clique em **Conectar**.

Cada autorização cria uma chave própria em **Chaves de API** no [painel](https://fonteza.com.br/app/login) (revogue lá para desconectar).

### Configurar com chave de API (`FONTEZA_KEY`)

**Claude Code**

```bash
claude mcp add --transport http fonteza https://fonteza.com.br/mcp \
  --header "Authorization: Bearer $FONTEZA_KEY"
```

**Cursor** (`~/.cursor/mcp.json`)

```json
{
  "mcpServers": {
    "fonteza": {
      "url": "https://fonteza.com.br/mcp",
      "headers": {
        "Authorization": "Bearer ${env:FONTEZA_KEY}"
      }
    }
  }
}
```

**VS Code** (`.vscode/mcp.json`)

```json
{
  "inputs": [
    { "id": "fonteza-key", "type": "promptString", "description": "Chave da API Fonteza", "password": true }
  ],
  "servers": {
    "fonteza": {
      "type": "http",
      "url": "https://fonteza.com.br/mcp",
      "headers": {
        "Authorization": "Bearer ${input:fonteza-key}"
      }
    }
  }
}
```

**Codex** (`~/.codex/config.toml`)

```toml
[mcp_servers.fonteza]
url = "https://fonteza.com.br/mcp"
bearer_token_env_var = "FONTEZA_KEY"
```

**Claude Desktop** (`claude_desktop_config.json`, requer Node.js; prefira o conector OAuth acima quando possível)

```json
{
  "mcpServers": {
    "fonteza": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://fonteza.com.br/mcp", "--header", "Authorization:${FONTEZA_AUTH}"],
      "env": {
        "FONTEZA_AUTH": "Bearer fk_sua_chave"
      }
    }
  }
}
```

### Ferramentas disponíveis

| Ferramenta | O que faz | Equivalente REST |
| --- | --- | --- |
| `consultar_empresas` | Busca por nome, atividade ou até 10 CNAEs, com telefone e e-mail cadastrais (até 50 por chamada). | [`/v1/buscar`](/referencia/buscar) |
| `consultar_mercado` | Empresas ativas por porte, aberturas e encerramentos por mês num setor e UF. | [`/v1/mercado`](/referencia/mercado) |
| `consultar_cnpj` | Cadastro, sócios e despesas federais de um CNPJ. | [`/v1/empresas/{cnpj}`](/referencia/empresas-cnpj) |

No MCP, apenas chamadas bem-sucedidas a ferramentas de dados consomem cota. Cota diária esgotada retorna erro JSON-RPC `-32029`; cota mensal esgotada retorna `-32005`.
