Conecte seu agente ao servidor MCP remoto da Fonteza para consultar empresas, CNPJs e números de mercado sem escrever código HTTP.

- **Endpoint:** `https://fonteza.com.br/mcp` (Streamable HTTP)
- **Autenticação:** OAuth 2.1 em conectores compatíveis ou `Authorization: Bearer fk_...`

## Claude (OAuth)

- **Claude Code (plugin):** `/plugin marketplace add fonteza/claude-plugins` → `/plugin install fonteza@fonteza` → `/mcp`
- **claude.ai / Claude Desktop:** **Configurações → Conectores → Adicionar conector personalizado** → informe `https://fonteza.com.br/mcp` → **Conectar**.

## Com chave de API (`FONTEZA_KEY`)

**Claude Code**

```bash
claude mcp add --transport http fonteza https://fonteza.com.br/mcp \
  --header "Authorization: Bearer $FONTEZA_KEY"
```

**Cursor** (`~/.cursor/mcp.json`)

```json
{
  "mcpServers": {
    "fonteza": {
      "url": "https://fonteza.com.br/mcp",
      "headers": {
        "Authorization": "Bearer ${env:FONTEZA_KEY}"
      }
    }
  }
}
```

**VS Code** (`.vscode/mcp.json`)

```json
{
  "inputs": [
    { "id": "fonteza-key", "type": "promptString", "description": "Chave da API Fonteza", "password": true }
  ],
  "servers": {
    "fonteza": {
      "type": "http",
      "url": "https://fonteza.com.br/mcp",
      "headers": {
        "Authorization": "Bearer ${input:fonteza-key}"
      }
    }
  }
}
```

**Codex** (`~/.codex/config.toml`)

```toml
[mcp_servers.fonteza]
url = "https://fonteza.com.br/mcp"
bearer_token_env_var = "FONTEZA_KEY"
```

**Claude Desktop** (`claude_desktop_config.json`, alternativa sem OAuth; requer Node.js)

```json
{
  "mcpServers": {
    "fonteza": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://fonteza.com.br/mcp", "--header", "Authorization:${FONTEZA_AUTH}"],
      "env": {
        "FONTEZA_AUTH": "Bearer fk_sua_chave"
      }
    }
  }
}
```

## Ferramentas

| Ferramenta | O que faz | Equivalente REST |
| --- | --- | --- |
| `consultar_empresas` | Busca por nome, atividade ou até 10 CNAEs (até 50 resultados por chamada). | [`/v1/buscar`](/referencia/buscar) |
| `consultar_cnpj` | Situação cadastral e dados da empresa. | [`/v1/empresas/{cnpj}`](/referencia/empresas-cnpj) |
| `consultar_mercado` | Empresas ativas por porte, aberturas e encerramentos por setor e UF. | [`/v1/mercado`](/referencia/mercado) |

No MCP, apenas chamadas bem-sucedidas a ferramentas consomem cota (`-32029` = cota diária esgotada; `-32005` = cota mensal esgotada).
