[`GET /v1/mercado`](/referencia/mercado) retorna contagens da Receita Federal em tempo real: empresas ativas por porte, aberturas e encerramentos nos últimos 60 meses, e ranking por município, CNAE ou faixa de capital.

Toda consulta exige **um setor** (`cnae`, `categoria` ou `grupo`) e **`uf`**.

```bash
curl -H "X-Api-Key: $FONTEZA_KEY" \
  "https://api.fonteza.com.br/v1/mercado?categoria=saloes-beleza&uf=SP&municipio=Campinas&agrupar_por=cnae"
```

## Filtros

| Parâmetro | O que filtra |
| --- | --- |
| `cnae` | Até 50 subclasses CNAE (7 dígitos), separadas por vírgula. |
| `categoria` | Slug de categoria de [`/v1/cnaes`](/referencia/cnaes) (ex.: `saloes-beleza`). |
| `grupo` | Grupo de categorias (ex.: `Beleza e bem-estar`). |
| `uf` | Sigla da UF (**obrigatória**). |
| `municipio` | Nome do município (sem diferenciar maiúsculas ou acentos). |
| `perfil` | `mei`, `me`, `epp`, `demais`, `nao_informado` (separados por vírgula). |
| `faixa_capital` | IDs de faixas de capital listados em [`/v1/meta`](/referencia/meta). |
| `agrupar_por` | `municipio`, `cnae` ou `faixa_capital` — retorna os 100 maiores em `grupos`. |

## Como ler os números

- **Apenas empresas (natureza `2xxx`).** Candidatos eleitorais (`4090`) ficam de fora para não distorcer tendências.
- **Estabelecimentos e CNAE principal.** Cada filial conta no seu município, apenas pela atividade principal.
- **Ativo vs. encerramento.** Ativo = situação `02`. Encerramento = `08` (baixada) ou `04` (inapta), no mês da situação. Meses sem movimentação são omitidos em `mensal` (preencha zeros no cliente).
- **MEI à parte.** `mei` inclui quem é ou já foi MEI, separado de `me`.
- **Capital social não é faturamento.** Reflete o valor declarado no contrato social, sem correção pela inflação, e repete o capital da matriz nas filiais.

Para listar as empresas por trás dos números, use a consulta equivalente devolvida no campo `busca` em [`/v1/buscar`](/referencia/buscar).

## Análise escrita pelo agente (assíncrona)

Contas liberadas podem pedir uma análise em Markdown gerada sobre os dados de `/v1/mercado` (até 20/dia):

```bash
curl -X POST -H "X-Api-Key: $FONTEZA_KEY" \
  -H "Content-Type: application/json" \
  -d '{"categoria": "saloes-beleza", "uf": "SP", "municipio": "Campinas", "objetivo": "abrir um salão"}' \
  https://api.fonteza.com.br/v1/agentes/mercado/execucoes
```

A rota responde `202` com o `id` da execução (header `Location`). Acompanhe em [`GET /v1/agentes/execucoes/{id}`](/referencia/agentes-execucoes-id) até `estado` ser `concluida` ou `falhou`.

### Webhook (opcional)

Envie `"webhook": true` no `POST` para receber o resultado por `POST` na URL HTTPS configurada na conta (retentativas em 1, 5 e 30 min se não responder `2xx` em 10 s). Valide a assinatura HMAC-SHA256 antes de processar:

```python
import hashlib, hmac, time

def assinatura_valida(segredo: str, timestamp: str, corpo: bytes, assinatura: str) -> bool:
    if abs(time.time() - int(timestamp)) > 300:
        return False
    esperada = hmac.new(segredo.encode(), f"{timestamp}.".encode() + corpo, hashlib.sha256).hexdigest()
    return hmac.compare_digest(esperada, assinatura)
```

Os headers enviados são `X-Fonteza-Timestamp`, `X-Fonteza-Assinatura` e `X-Fonteza-Execucao` (use para idempotência).
