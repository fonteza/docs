`GET /v1/empresas/{cnpj}/despesas-federais` · requer `X-Api-Key`

Empenhos, liquidações e pagamentos federais do Portal da Transparência para um CNPJ.

## Exemplo

```bash
curl \
  -H "X-Api-Key: $FONTEZA_KEY" \
  "https://api.fonteza.com.br/v1/empresas/12345678000190/despesas-federais?limit=5"
```

## Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `cnpj` | string | sim | CNPJ normalizado do favorecido; 12 caracteres alfanuméricos e dois dígitos verificadores. |
| `escopo` | string | não | Raiz consulta CNPJs com os mesmos oito primeiros caracteres; estabelecimento exige CNPJ exato. Valores: `raiz`, `estabelecimento`. Padrão: `"raiz"`. |
| `fase` | string | não | Fase documental oficial; fases não são somadas entre si. Valores: `empenho`, `liquidacao`, `pagamento`. |
| `data_de` | string (date) | não | Primeira data de emissão, inclusive; não amplia a janela de arquivos publicada. |
| `data_ate` | string (date) | não | Última data de emissão, inclusive; não amplia a janela de arquivos publicada. |
| `limit` | integer | não | Padrão: `20`. |
| `cursor` | string | não | Cursor opaco vinculado à geração, ao CNPJ, ao escopo e aos filtros. |

## Notas

- `escopo=raiz` (padrão) inclui matriz e filiais; `escopo=estabelecimento` filtra o CNPJ exato.
- Paginação por cursor (`next_cursor`): em `409 geracao_despesas_expirada`, recomece sem cursor.

Schema completo em [openapi.yaml](https://fonteza.com.br/openapi.yaml).

## Erros

| Status | Código | Quando |
| --- | --- | --- |
| 409 | `geracao_despesas_expirada` | A geração do cursor deixou de ser a publicação atual. |

Erros comuns e limites: [Autenticação, limites e erros](/autenticacao#erros).
