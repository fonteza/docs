`GET /v1/cnaes` · pública, sem chave

Traduz palavras de atividade (ex.: `restaurante`, `dentista`) em códigos CNAE de 7 dígitos. Rota pública.

## Exemplo

```bash
curl "https://api.fonteza.com.br/v1/cnaes?q=restaurante"
```

## Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `q` | string | não | Atividade, profissão ou código CNAE. |
| `todos` | boolean | não | true lista todos os códigos que o filtro cnae de /v1/buscar aceita (um item por código, em ordem), sem q, limit nem completar. Padrão: `false`. |
| `limit` | integer | não | Padrão: `10`. |
| `completar` | boolean | não | Para digitação: a última palavra pode estar incompleta (restau). Padrão: `false`. |

Schema completo em [openapi.yaml](https://fonteza.com.br/openapi.yaml).
