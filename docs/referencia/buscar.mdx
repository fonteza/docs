`GET /v1/buscar` · requer `X-Api-Key`

Busca estabelecimentos ativos (`situacao_cadastral: 02`) por nome, atividade, CNPJ ou CNAE.

## Exemplo

```bash
curl \
  -H "X-Api-Key: $FONTEZA_KEY" \
  "https://api.fonteza.com.br/v1/buscar?q=transportadora&uf=SP"
```

## Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `q` | string | não | Nome, razão social, atividade ou CNPJ, de 2 a 120 caracteres. |
| `uf` | string | não | Sigla da UF do estabelecimento. |
| `municipio` | string | não | Nome do município, sem diferenciar maiúsculas nem acentos (sao paulo equivale a São Paulo); hífens e apóstrofos contam. |
| `cnae` | string | não | Código CNAE principal, ou até 10 códigos separados por vírgula (uma categoria de /v1/cnaes pode ter vários). |
| `somente_matriz` | boolean | não | Exclui filiais. Padrão: `false`. |
| `ordenar_por` | string | não | Valores: `relevancia`, `nome`, `municipio`, `uf`, `capital_social`, `data_inicio_atividade`, `cnae`. Padrão: `"relevancia"`. |
| `ordem` | string | não | Valores: `asc`, `desc`. Padrão: `"desc"`. |
| `porte` | string | não | Códigos de porte da RFB separados por vírgula: 00 não informado, 01 microempresa, 03 empresa de pequeno porte, 05 demais. |
| `capital_min` | number | não | Capital social mínimo em reais. |
| `capital_max` | number | não | Capital social máximo em reais; não pode ser menor que capital_min. |
| `data_inicio_de` | string (date) | não | Início de atividade a partir desta data (AAAA-MM-DD). |
| `data_inicio_ate` | string (date) | não | Início de atividade até esta data (AAAA-MM-DD). |
| `tem_email` | boolean | não | true exige e-mail cadastrado; false exige ausência. |
| `tem_telefone` | boolean | não | true exige telefone cadastrado; false exige ausência. |
| `simples` | string | não | Opção pelo Simples Nacional. Valores: `S`, `N`. |
| `mei` | string | não | Opção pelo MEI. Valores: `S`, `N`. |
| `incluir_total` | boolean | não | Calcula o total exato de resultados; sem ele, total vem null. Padrão: `false`. |
| `incluir_contagem` | boolean | não | Conta os resultados até 1.000 e devolve contagem; acima disso, contagem.excede_limite vem true. Padrão: `false`. |
| `confirmar_varredura` | boolean | não | Confirma uma busca ampla recusada com 409 e amplia o tempo limite de 12 para 60 segundos. Padrão: `false`. |
| `limit` | integer | não | Padrão: `20`. |
| `offset` | integer | não | Deslocamento da página. Padrão: `0`. |

## Notas

- Informe `q`, `cnae` ou ambos. Use os códigos de `meta.cnaes_sugeridos` para buscas rápidas por atividade.
- `total` vem `null` por padrão; use `incluir_contagem=true` (rápido, até 1.000) ou `incluir_total=true`.
- Buscas amplas retornam `409 busca_ampla_requer_confirmacao`: refine os filtros ou envie `confirmar_varredura=true`.

Schema completo em [openapi.yaml](https://fonteza.com.br/openapi.yaml).

## Erros

| Status | Código | Quando |
| --- | --- | --- |
| 409 | `busca_ampla_requer_confirmacao` `busca_demorada` | Busca ampla demais para executar sem confirmação, ou interrompida após 12 segundos. |
| 422 | `municipio_uf_incompativel` | Parâmetro inválido ou município incompatível com a UF. |
| 504 | `busca_demorada` | Busca confirmada interrompida após 60 segundos. |

Erros comuns e limites: [Autenticação, limites e erros](/autenticacao#erros).
