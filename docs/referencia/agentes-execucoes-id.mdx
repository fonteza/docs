`GET /v1/agentes/execucoes/{id}` · requer o header `X-Api-Key`

A execução como está agora: na_fila, executando, concluida ou falhou. Uma execução concluída traz em resultado a análise (analise), as respostas de /v1/mercado que o agente usou (mercado) e a competência da base. Todo número da análise aparece nessas respostas; uma análise com número que não aparece não é entregue. Uma execução que falhou traz o código do erro em erro: tentativas_esgotadas (o processo caiu três vezes), numeros_nao_conferem, agente_indisponivel, prazo_esgotado, consulta_indisponivel (os números não puderam ser lidos) ou acesso_desativado (o acesso da conta ao agente foi desligado). Cada execução é tentada até 3 vezes. Só a conta que pediu a execução a enxerga; o id de outra conta responde 404.

## Exemplo

```bash
curl \
  -H "X-Api-Key: $FONTEZA_KEY" \
  https://api.fonteza.com.br/v1/agentes/execucoes/5f0c4a1e-2b7d-4c39-9a51-0d6e8b3f7a21
```

## Parâmetros

| Parâmetro | Tipo | Onde | Obrigatório | Descrição |
| --- | --- | --- | --- | --- |
| `id` | string (uuid) | caminho | sim | Id da execução, devolvido ao criá-la. |

## Resposta 200

A execução.

- `id` (string (uuid))
- `agente` ("mercado")
- `estado` (string): Valores: `na_fila`, `executando`, `concluida`, `falhou`.
- `entrada` (objeto)
  - `filtros` (objeto): Os filtros enviados, só os informados.
  - `objetivo` (string)
  - `webhook` (boolean)
- `resultado` (null | objeto): Presente quando estado é concluida.
- `erro` (string | null): Código do erro quando estado é falhou.
- `tentativas` (integer)
- `webhook` (string | null): Entrega por webhook; null quando não foi pedida. Valores: `pendente`, `entregue`, `falhou`.
- `criada_em` (string (date-time))
- `iniciada_em` (string | null (date-time))
- `concluida_em` (string | null (date-time))

## Erros

| Status | Quando | Código |
| --- | --- | --- |
| 404 | Nenhuma execução com este id nesta conta. | `execucao_nao_encontrada` |

Erros comuns (401, 403, 429, 503): veja [Autenticação, cota e erros](/autenticacao#erros).
