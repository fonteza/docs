`GET /v1/agentes/execucoes/{id}` · requer `X-Api-Key`

Retorna o estado (`na_fila`, `executando`, `concluida`, `falhou`) e o resultado de uma análise de agente.

## Exemplo

```bash
curl \
  -H "X-Api-Key: $FONTEZA_KEY" \
  https://api.fonteza.com.br/v1/agentes/execucoes/5f0c4a1e-2b7d-4c39-9a51-0d6e8b3f7a21
```

## Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `id` | string (uuid) | sim | Id da execução, devolvido ao criá-la. |

Schema completo em [openapi.yaml](https://fonteza.com.br/openapi.yaml).

## Erros

| Status | Código | Quando |
| --- | --- | --- |
| 404 | `execucao_nao_encontrada` | Nenhuma execução com este id nesta conta. |

Erros comuns e limites: [Autenticação, limites e erros](/autenticacao#erros).
