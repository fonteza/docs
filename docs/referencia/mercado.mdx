`GET /v1/mercado` · requer `X-Api-Key`

Contagens da Receita em tempo real: empresas ativas por porte, aberturas/encerramentos (60 meses) e rankings.

## Exemplo

```bash
curl \
  -H "X-Api-Key: $FONTEZA_KEY" \
  "https://api.fonteza.com.br/v1/mercado?cnae=9602501&uf=SP&municipio=Campinas"
```

## Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `cnae` | string | não | Subclasses CNAE principais de 7 dígitos, até 50, separadas por vírgula; pontos, hífens e barras são ignorados. |
| `categoria` | string | não | Slug de uma categoria de /v1/cnaes, como saloes-beleza. |
| `grupo` | string | não | Grupo de categorias, como Beleza e bem-estar. |
| `uf` | string | sim | Sigla da UF. |
| `municipio` | string | não | Nome do município, sem diferenciar maiúsculas nem acentos. |
| `perfil` | string | não | Perfis separados por vírgula: mei, me, epp, demais, nao_informado. |
| `faixa_capital` | string | não | Ids de faixas de capital social separados por vírgula, de /v1/meta (data.faixas_capital). |
| `agrupar_por` | string | não | Acrescenta grupos, os 100 maiores por total de ativos. Valores: `municipio`, `cnae`, `faixa_capital`. |

## Notas

- Informe **exatamente um setor** (`cnae`, `categoria` ou `grupo`) e **`uf`**.
- Conta apenas empresas (`2xxx`, sem candidatos eleitorais), por estabelecimento e CNAE principal.
- Ativo = `02`; encerramento = `08` (baixada) ou `04` (inapta). Meses zerados são omitidos em `mensal`.
- `mei` é contado à parte de `me`. `capital_social` é o valor declarado no contrato, não faturamento.
- Use o campo `busca` da resposta para listar as empresas correspondentes em `/v1/buscar`.

Schema completo em [openapi.yaml](https://fonteza.com.br/openapi.yaml).

## Erros

| Status | Código | Quando |
| --- | --- | --- |
| 422 | `municipio_uf_incompativel` | Parâmetro inválido ou município incompatível com a UF. |
