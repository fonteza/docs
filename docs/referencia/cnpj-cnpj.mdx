`GET /v1/cnpj/{cnpj}` · requer o header `X-Api-Key`

Cadastro na raiz do JSON, na publicação RFB vigente. Envie sua chave Fonteza em X-Api-Key.

## Exemplo

```bash
curl \
  -H "X-Api-Key: $FONTEZA_KEY" \
  https://api.fonteza.com.br/v1/cnpj/00000000000191
```

## Parâmetros

| Parâmetro | Tipo | Onde | Obrigatório | Descrição |
| --- | --- | --- | --- | --- |
| `cnpj` | string | caminho | sim | CNPJ completo com 14 caracteres. Pontos e hífen são removidos e letras viram maiúsculas (CNPJ alfanumérico); a barra não é aceita no caminho e resulta em 404. Os dígitos verificadores não são conferidos. Ao menos 14 caracteres. |

## Resposta 200

Cadastro do estabelecimento e sócios da empresa.

- `status` ("OK")
- `ultima_atualizacao` (string (date-time))
- `cnpj` (string)
- `tipo` (string)
- `porte` (string)
- `nome` (string)
- `fantasia` (string)
- `abertura` (string)
- `atividade_principal` (array de objeto)
  - `code` (string)
  - `text` (string)
- `atividades_secundarias` (array de objeto)
  - `code` (string)
  - `text` (string)
- `natureza_juridica` (string)
- `logradouro` (string)
- `numero` (string)
- `complemento` (string)
- `cep` (string)
- `bairro` (string)
- `municipio` (string)
- `uf` (string)
- `email` (string)
- `telefone` (string)
- `efr` (string)
- `situacao` (string)
- `data_situacao` (string)
- `motivo_situacao` (string)
- `situacao_especial` (string)
- `data_situacao_especial` (string)
- `capital_social` (string)
- `qsa` (array de objeto)
  - `nome` (string)
  - `qual` (string)
  - `pais_origem` (string, opcional)
  - `nome_rep_legal` (string, opcional)
  - `qual_rep_legal` (string, opcional)
- `simples` (objeto)
  - `optante` (boolean)
  - `data_opcao` (string | null)
  - `data_exclusao` (string | null)
  - `ultima_atualizacao` (string (date-time))
- `simei` (objeto)
  - `optante` (boolean)
  - `data_opcao` (string | null)
  - `data_exclusao` (string | null)
  - `ultima_atualizacao` (string (date-time))
- `extra` (objeto)
- `billing` (objeto)
  - `free` (false)
  - `database` (true)
