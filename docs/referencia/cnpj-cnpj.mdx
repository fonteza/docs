`GET /v1/cnpj/{cnpj}` · requer `X-Api-Key`

Consulta um CNPJ no formato compatível com a ReceitaWS (campos na raiz do JSON).

## Exemplo

```bash
curl \
  -H "X-Api-Key: $FONTEZA_KEY" \
  https://api.fonteza.com.br/v1/cnpj/00123456000190
```

## Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `cnpj` | string | sim | CNPJ completo com 14 caracteres. |
