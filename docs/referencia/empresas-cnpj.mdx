`GET /v1/empresas/{cnpj}` · requer `X-Api-Key`

Cadastro completo e quadro de sócios de um CNPJ (qualquer situação cadastral).

## Exemplo

```bash
curl \
  -H "X-Api-Key: $FONTEZA_KEY" \
  https://api.fonteza.com.br/v1/empresas/12345678000190
```

## Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `cnpj` | string | sim | CNPJ completo com 14 caracteres. |

## Notas

- `situacao_cadastral`: `01` nula, `02` ativa, `03` suspensa, `04` inapta, `08` baixada.
- `porte`: `00` não informado, `01` microempresa, `03` EPP, `05` demais.
- `matriz_filial`: `1` matriz, `2` filial. Datas em `AAAAMMDD` e `capital_social` com vírgula (`150000,00`).
- `socios[].cpf_mascarado` preserva o mascaramento oficial da Receita Federal.

Schema completo em [openapi.yaml](https://fonteza.com.br/openapi.yaml).
