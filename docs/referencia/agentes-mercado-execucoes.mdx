`POST /v1/agentes/mercado/execucoes` · requer `X-Api-Key`

Enfileira uma análise escrita em Markdown sobre `/v1/mercado` (assíncrona, retorna `202`, até 20/dia para contas liberadas).

## Exemplo

```bash
curl \
  -X POST \
  -H "X-Api-Key: $FONTEZA_KEY" \
  -H "Content-Type: application/json" \
  -d '{"categoria": "saloes-beleza", "uf": "SP", "municipio": "Campinas", "objetivo": "abrir um salão de beleza", "webhook": false}' \
  https://api.fonteza.com.br/v1/agentes/mercado/execucoes
```

## Corpo JSON

- `cnae` (string, opcional): Como em /v1/mercado: um entre cnae, categoria e grupo é obrigatório.
- `categoria` (string, opcional): Como em /v1/mercado.
- `grupo` (string, opcional): Como em /v1/mercado.
- `uf` (string): Como em /v1/mercado; obrigatória.
- `municipio` (string, opcional): Como em /v1/mercado.
- `perfil` (string, opcional): Como em /v1/mercado.
- `faixa_capital` (string, opcional): Como em /v1/mercado.
- `agrupar_por` (string, opcional): Como em /v1/mercado. Valores: `municipio`, `cnae`, `faixa_capital`.
- `objetivo` (string): Para que serve a análise, em texto livre.
- `webhook` (boolean, opcional): Entregar a execução, quando terminar, na URL de webhook da conta (configurada no app).

## Notas

Acompanhe o resultado em [`GET /v1/agentes/execucoes/{id}`](/referencia/agentes-execucoes-id) ou envie `"webhook": true` para receber por `POST` na URL HTTPS da conta.

Validação da assinatura HMAC-SHA256 (`X-Fonteza-Timestamp` + `X-Fonteza-Assinatura`):

```python
import hashlib, hmac, time

def assinatura_valida(segredo: str, timestamp: str, corpo: bytes, assinatura: str) -> bool:
    if abs(time.time() - int(timestamp)) > 300:
        return False
    esperada = hmac.new(segredo.encode(), f"{timestamp}.".encode() + corpo, hashlib.sha256).hexdigest()
    return hmac.compare_digest(esperada, assinatura)
```

Schema completo em [openapi.yaml](https://fonteza.com.br/openapi.yaml).

## Erros

| Status | Código | Quando |
| --- | --- | --- |
| 422 | `webhook_nao_configurado` | Corpo ou filtro inválido, município desconhecido ou fora da UF (com sugestões, como em /v1/mercado), ou webhook pedido sem URL de webhook configurada na conta (webhook_nao_configurado). |
