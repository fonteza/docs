`GET /v1/empresas/{cnpj}/dossie` · requer `X-Api-Key`

Reúne fatos com evidência, regras de alerta e status de cada fonte sobre um CNPJ (sem nota de risco).

## Exemplo

```bash
curl \
  -H "X-Api-Key: $FONTEZA_KEY" \
  https://api.fonteza.com.br/v1/empresas/12345678000190/dossie
```

## Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `cnpj` | string | sim | CNPJ completo com 14 caracteres. |

## Notas

### Estados de `verificacoes`

| Estado | Significado |
| --- | --- |
| `verificado` | Fonte consultada com dados encontrados. |
| `nada_encontrado` | Nada encontrado na janela consultada. |
| `nao_verificado` | Fonte não consultada — **nunca leia como ausência de registro**. |

### Regras de alerta (`2026-11`)

| Código | Severidade | Quando aciona |
| --- | --- | --- |
| `SITUACAO_NAO_ATIVA` | alta | Situação cadastral diferente de ativa (`02`). |
| `NATUREZA_CANDIDATO` | alta | CNPJ de candidatura eleitoral. |
| `EMPRESA_RECENTE` | media | Início de atividade há menos de 12 meses. |
| `SOCIO_ENTROU_RECENTEMENTE` | media | Entrada de sócio há menos de 90 dias. |
| `CONTRATO_VIGENTE_EMPRESA_NAO_ATIVA` | media | Contrato federal vigente com CNPJ não ativo. |
| `CONTRATO_PUBLICO_VIGENTE` | info | Contrato federal vigente na data da consulta. |
| `MEI` | info | Optante pelo MEI. |
| `SEM_QSA` | info | Sem sócios publicados (exceto MEI/EI). |

Schema completo em [openapi.yaml](https://fonteza.com.br/openapi.yaml).
